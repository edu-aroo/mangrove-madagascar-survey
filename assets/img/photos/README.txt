Photos de la page (bandeau, accueil, sections, remerciements).
Par défaut, la page charge les photos depuis Wikimedia Commons. Pour les héberger
avec le site (recommandé : plus rapide, indépendant de Wikimedia), lancer une fois
dans R depuis le dossier enquete-mangroves/ :  source("tools/download_photos.R")
Les fichiers sont alors enregistrés ici sous le nom indiqué dans SURVEY.PHOTOS (key.jpg).

Crédits : Wikimedia Commons, licences CC0 / CC BY 4.0 / CC BY-SA 2.0, 3.0, 4.0 — auteur indiqué
pour chaque photo dans survey-config.js (Smiley.toerist, 007RA, Rudolphfurtado, Anai171,
Chirocca77, Bernard Dupont).
L'attribution (auteur + licence + lien) est affichée sur chaque photo : ne pas la retirer.
Pour utiliser vos propres photos de terrain, les déposer ici et mettre à jour
src / caption / credit / license / page dans survey-config.js.
